# 2026-07-28 개발 로그

## 작업 단계

- 단계: 주간 AI 리포트 핵심 경로 마감
- 상태: Milestone 1–3 완료, Milestone 4–5 연기
- 범위: 주간 AI 리포트 생성·조회·확정, 기본/AI PDF 다운로드, 검증

## 완료한 작업

- 대시보드에는 AI 리포트 요약만 유지하고 전체 리포트를 전용 URL로 분리했다.
- `SUMMARY | STANDARD | DETAILED` 표시 밀도와 BASELINE, 서버 위험, AI 위험을 구분했다.
- 기본 리포트와 확정된 AI 리포트를 서버 생성 PDF attachment로 다운로드하도록 했다.
- `TaskMetricsSnapshotSource`가 task repository를 직접 읽지 않고
  `TaskReportDataQuery` application 계약을 사용하도록 경계를 정리했다.
- 무료 기본 PDF는 검증·렌더링 뒤 짧은 기록 트랜잭션에서만 그룹 잠금을 잡도록
  `validate`와 `record`를 분리했다.
- 같은 그룹·주차·언어의 성공한 AI 생성·재생성을 최대 3회로 제한했다.
- PDF 서술에 검증된 evidence key와 task/objective 참조를 포함했다.

## 영향 범위

- API: 기본 PDF와 AI PDF attachment, 주간 AI 리포트 생명주기 및 상세 조회
- DB: Flyway V23–V26의 report, activity snapshot, context, editorial lifecycle
- 환경변수: OpenAI 모델·timeout·generation lease·PDF font 설정
- 정책: PAID TEAM LEADER만 생성, 활성 MEMBER는 확정본 조회·다운로드

## 연기

- Milestone 4의 이전 권고 결과·위험 효과 평가는 새 frozen schema/domain 계약이
  필요하므로 별도 후속 작업으로 연기했다.
- Milestone 5의 팀 프런트 시각 검토만 후속 작업이다. 공개 랜딩에는 API/OpenAI 호출이 없는
  고정 예시 미리보기를 구현했다.

## 2026-07-29 문서·계약 정합성 보강

blocker enum과 OpenAI 요청 timeout 계약을 코드·설정에 맞추고 AI 리포트 상세 계약을
`docs/spec/AiWeeklyReport.md`로 통합했다. 집중 테스트
`TaskActivityMetricsSnapshotSourceTest`, `OpenAiResponsesNarrativeAdapterTest` 9건이 통과했으며
실제 OpenAI provider 검증은 아직 미완료다.
- 실제 OpenAI 키를 사용한 품질·거절·timeout·비용 검증은 수행하지 않았으며,
  deterministic test provider 결과를 실제 provider 검증으로 주장하지 않는다.

## 검증

- 좁은 report 테스트 11개 통과:
  `.\mvnw.cmd -q "-Dtest=TaskActivityMetricsSnapshotSourceTest,WeeklyReportLifecycleTest,WeeklyReportApiTest" test`
- 기본 리포트 접근 API 테스트 통과:
  `.\mvnw.cmd -q "-Dtest=GroupInvitationApiTest" test`
- 전체 backend, MySQL Flyway, frontend build, Chrome E2E와 최종 diff 검사는
  이 로그의 마감 검증에서 갱신한다.

## 보안

- OpenAI API key, access token, fixture 비밀번호를 로그나 저장소에 기록하지 않았다.
- provider 입력은 익명화된 집계·별칭 계약을 유지한다.
